# Créditos de assets

**Regla:** ningún modelo, textura o animación entra al repo sin una fila aquí con
licencia que permita redistribución. Si la licencia no es clara → no se sube.

| Archivo               | Autor | Fuente (URL) | Licencia | Redistribución | Notas |
| --------------------- | ----- | ------------ | -------- | -------------- | ----- |
| _(vacío — ver T-203)_ |       |              |          |                |       |

Para VRM revisa los metadatos del propio archivo (`meta` en VRM 1.0:
`licenseUrl`, `allowRedistribution`, `commercialUsage`, `modification`).
